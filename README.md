# ZHAW — Portafolio de Jorge Gutierrez Vallejo

Portafolio personal bilingüe (ES / EN) de **Jorge Gutierrez Vallejo (Zhaw)**, Creative Developer.

> Súbele el volumen a tu proyecto.

## Tecnologías

- HTML
- CSS
- JavaScript

Sin frameworks ni dependencias: basta con abrir `index.html` en el navegador.

## Estructura

```
index.html         Página principal
styles.css         Estilos
script.js          Interacciones y traducciones ES / EN
data/projects.js   Proyectos de la sección ZHAW TV
assets/            Imágenes, fuentes, íconos y CV
images/            Logo y favicon
```

## Agregar un proyecto

Edita `data/projects.js`, copia un bloque existente y cambia sus datos. La categoría (`web`, `design` o `video`) define en qué filtro aparece. Las portadas van en `assets/images/projects/covers/` y las fotos del caso de estudio en `assets/images/projects/case/`.
